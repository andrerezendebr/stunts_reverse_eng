Reimplementação de Stunts em Rust — início

Este projeto começa pelas ferramentas de análise. Ainda não executa o jogo.
Não altera os arquivos originais. Não possui dependências externas.

Na pasta stunts-rs:
  cargo run -- inventory ..\stunts_dos
  cargo run -- inspect ..\stunts_dos\LOAD.EXE
  cargo run -- inspect ..\stunts_dos\MCGA.HDR

Direção do trabalho:
1. Confirmar a versão e reconstruir a imagem descomprimida do jogo.
2. Usar o projeto Ghidra em ..\reverse\projects\Stunts.gpr para documentar rotinas.
3. Implementar leitores dos recursos com limites e formatos confirmados.
4. Portar matemática, estado dos carros e física usando larguras de inteiros
   e comportamento de overflow correspondentes ao código DOS.
5. Comparar estados por frame com replays originais antes de integrar vídeo,
   entrada e áudio modernos.

O Ghidra auxilia na leitura de assembly e pseudocódigo C. A tradução para Rust
será feita por rotina, com validação de comportamento; não é conversão automática.
Os endereços e nomes de funções de outros projetos só devem ser usados depois
de confirmar a correspondência com esta versão.
